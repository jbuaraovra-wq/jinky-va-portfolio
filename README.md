# Jinky Buarao — Virtual Assistant Portfolio

Responsive static portfolio website using the new Color Hunt palette:
- Soft yellow: #fff9d2
- Warm peach: #ffebcc
- Light blue: #bfddf0
- Sky blue: #8cc0eb
- Charcoal text: #282b38
- White: #ffffff

Fonts: DM Sans and Manrope, with system font fallbacks.

## Before publishing
1. Replace `YOUR.EMAIL@example.com` with your professional email address.
2. Update LinkedIn and Instagram links to your actual profiles.
3. Replace sample project links and cards with your real work.
4. Keep `assets/jinky-profile.jpeg` alongside the website file in the assets folder.
5. Do not publish client information, prospect email addresses, or private documents without permission.

## Deploy to Vercel
1. Extract this ZIP.
2. Upload `index.html` and the `assets` folder to a GitHub repository.
3. Sign in at https://vercel.com and choose **Add New → Project**.
4. Import your GitHub repository and deploy the static site with no build command.
5. Vercel provides a public `.vercel.app` URL.

Official docs: https://vercel.com/docs/deployments
